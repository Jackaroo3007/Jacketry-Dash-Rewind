# Jacketry Dash Rewind

A small GitHub test repository with a browser-based roll demo.

## Lucky Roll

Open `index.html` in a browser or publish the repository with GitHub Pages. The demo awards points for random rarity rolls and saves progress in the current browser.

- No account or server is required.
- Points have no real-world value.
- The Mythic test button previews the animation without changing the saved score.
- Exported roll logs are browser-made snapshots and are not independently verified.

`stats.json` contains the repository's separate level-progress data.
